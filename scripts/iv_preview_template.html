What each SMU acquires

Each active SMU measures exactly one quantity throughout each hardware sweep. No software stepping or extra spot measurements.

What the saved columns mean

Four terminal quantities, then time and combined status. A genuinely unavailable quantity has no column. GNDU uses NaN, never a fictitious measured zero. Missing records in an interrupted point are empty cells.
